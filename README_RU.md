Это кастомное ядро для **Poco M3 (Citrus)**, ориентированное на стабильность, бесшовную интеграцию root-прав и полную совместимость с кастомными прошивками на базе Android 16.

## Особенности релиза
* **KernelSU Next (Legacy)**: Интегрирована актуальная ветка legacy (билд `33132`), необходимая для корректной работы на ядрах 4.19 (non-GKI).
* **Универсальная поддержка менеджеров**: Верификация менеджера осуществляется исключительно по криптографической подписи. Вдохновленное проектами вроде ShockWAVE, решение позволяет использовать официальный и скрытые (spoofed) менеджеры.
* **Встроенный драйвер WLAN**: Драйвер Wi-Fi `qca_cld3` скомпилирован напрямую в ядро (`=y`). Обходит ограничения заблокированного раздела vendor.

## Инструкция по установке
1. **Подготовка**: Убедитесь, что используете актуальную версию TWRP или OrangeFox Recovery.
2. **Прошивка**: Скачайте архив со страницы релизов и установите `zip` через Recovery.
3. **Установка менеджера**: Установите KernelSU Next Manager (официальный или spoofed).
4. **Перезагрузка**: Перезагрузите устройство.
